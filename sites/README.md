# Content Pages

This folder contains normal public content pages.

Route examples:

- `overview/test` loads `sites/overview/test/de.html` or `sites/overview/test/en.html`.
- `about/contact` loads `sites/about/contact/de.html` or `sites/about/contact/en.html`.

`home/` stays reserved for the start page, `mod/` for module pages, and `admin/` for controllers and functional areas.
