# PNA Brand Architecture

<a id="X1c9d4102fa9a71a9844b39384f6dec7e62fb394"></a>

## Markenarchitektur, Positionierung und Produktlogik

<a id="version-1.0-frozen-canon"></a>

### Version 1\.0 – Frozen Canon

<a id="grundidee"></a>

# 1\. Grundidee

PNA ist mehr als ein Persönlichkeitstest\.

PNA ist ein System zur Orientierung, Entwicklung und Sichtbarmachung von Authentizität\.

Die Markenarchitektur verfolgt deshalb drei Ziele:

1. Wissenschaftliche Glaubwürdigkeit
2. Hohe Zugänglichkeit
3. Hohe Wiedererkennbarkeit

Die Marke muss gleichzeitig:

- wissenschaftlich belastbar wirken
- einfach verständlich sein
- visuell attraktiv sein
- social\-media\-tauglich sein
- skalierbar sein

<a id="markenpyramide"></a>

# 2\. Markenpyramide

Die Markenarchitektur folgt einer hierarchischen Struktur\.

PNA  
│  
├── PNA Navigator  
├── PNA Core  
├── PNA Lab  
├── PNA Insights  
├── PNA Academy  
└── PNA Certification

<a id="dachmarke"></a>

# 3\. Dachmarke

<a id="pna"></a>

## PNA

<a id="persona-natura-authentica"></a>

### Persona Natura Authentica

Leitidee:

In Search of Authenticity

Mission:

Menschen dabei unterstützen, ihre natürliche Orientierung zu erkennen und bewusst einzusetzen\.

PNA steht nicht für Typisierung\.

PNA steht für Orientierung\.

<a id="pna-navigator"></a>

# 4\. PNA Navigator

Der Navigator ist die eigentliche Plattform\.

Er umfasst:

- Tests
- Reports
- Profile
- Vergleiche
- Entwicklungsanalysen

Der Navigator ist der primäre Berührungspunkt für Anwender\.

<a id="pna-core"></a>

# 5\. PNA Core

Der Core enthält die eigentlichen Modelle\.

Aktuell:

64 Kernmodelle  
32 Business\-Modelle  
32 Personal\-Modelle

Der Core bildet die diagnostische Basis des Systems\.

<a id="pna-lab"></a>

# 6\. PNA Lab

Das Lab ist die Forschungs\- und Entwicklungsumgebung\.

Aufgaben:

- Entwicklung neuer Modelle
- Validierung bestehender Modelle
- Testentwicklung
- Itementwicklung
- Mapping
- Qualitätskontrolle

Das Lab ist die Heimat der Modellarchitektur\.

<a id="pna-insights"></a>

# 7\. PNA Insights

Insights umfasst:

- Reports
- Analysen
- Teamprofile
- Entwicklungsberichte
- Vergleichsstudien

Ziel:

Orientierung aus Ergebnissen ableiten\.

<a id="pna-academy"></a>

# 8\. PNA Academy

Die Academy umfasst:

- Ausbildungen
- Workshops
- Seminare
- Zertifizierungen
- Anwendungswissen

Ziel:

Menschen befähigen, mit PNA zu arbeiten\.

<a id="pna-certification"></a>

# 9\. PNA Certification

Die Certification definiert offizielle Standards\.

Beispiele:

- Certified PNA Practitioner
- Certified PNA Coach
- Certified PNA Consultant
- Certified PNA Trainer

# 10\. Family Brands

- Storytelling

<a id="die-vermessung-der-persönlichkeit"></a>

# 21\. Die Vermessung der Persönlichkeit

PNA versteht Persönlichkeit als Landkarte\.

Die Modelle sind unterschiedliche Perspektiven auf dieselbe Landschaft\.

Die Archetypen sind Orientierungspunkte\.

Die Achsen sind Spannungsfelder\.

Die Auswertung erzeugt kein Etikett\.

Sie erzeugt Orientierung\.

<a id="markenversprechen"></a>

# 22\. Markenversprechen

PNA hilft Menschen,

- sich selbst besser zu verstehen
- andere besser zu verstehen
- bewusster zu handeln
- authentischer zu werden

Leitsatz:

In Search of Authenticity

<a id="zielbild"></a>

# 23\. Zielbild

Die Marke soll langfristig wahrgenommen werden als:

wissenschaftlich  
verständlich  
modern  
visuell stark  
menschlich  
zugänglich  
authentisch

PNA verbindet psychologische Tiefe mit einfacher Sprache und einer klaren visuellen Identität\.

Damit entsteht ein System, das gleichermaßen für Forschung, Beratung, Entwicklung und persönliche Orientierung eingesetzt werden kann\.
